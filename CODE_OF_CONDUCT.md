# Código de conduta

## O compromisso

Este projeto é aberto a qualquer pessoa, independentemente de nível de
experiência, identidade de gênero, orientação sexual, deficiência, aparência,
etnia, idade, religião ou nacionalidade.

## O que se espera

- Trate as pessoas com respeito, inclusive quando discordar delas.
- Critique o código, não quem escreveu.
- Aceite crítica construtiva sobre o seu próprio trabalho.
- Não presuma conhecimento prévio. Este projeto atrai tanto engenheiros de áudio
  quanto pessoas aprendendo a produzir — as duas coisas são bem-vindas, e
  perguntas básicas não são incômodo.
- Assuma boa-fé.

## O que não é aceitável

- Assédio de qualquer tipo, público ou privado.
- Comentários depreciativos sobre características pessoais.
- Publicar informação privada de terceiros sem autorização.
- Insistir em discussões depois de um pedido claro para parar.

## Aplicação

Comportamento inaceitável pode ser relatado abrindo uma issue marcada como
confidencial ou contatando os mantenedores diretamente. Todos os relatos serão
analisados e respondidos.

Os mantenedores podem remover comentários, commits, código e issues que violem
este código, e banir temporária ou permanentemente quem o violar de forma
repetida.

## Escopo

Aplica-se a todos os espaços do projeto — issues, pull requests, discussões — e
quando alguém representa o projeto publicamente.
